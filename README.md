# City Care Hospital Web Development Laboratory

This folder contains the healthcare website developed for the Web Development Laboratory.

- `exp1.html` - Experiment 1 HTML-only healthcare portal.
- `exp2.html` - Experiment 2 styled and responsive portal.
- `style.css` - external CSS theme and responsive layout.
- `facilities.html`, `appointment.html`, `sign_in.html`, `sign_up.html` - supporting portal pages.
- `images/hospital-hero.png` - local website image.
- `script.js` - appointment form validation used in the portal.

Open `exp2.html` in a browser to view the CSS-enhanced portal. Use only sample information in forms.
